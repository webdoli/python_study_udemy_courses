[파이썬 가상환경 만드는 법]
- 모듈끼리 부딪치면 안 되므로 각 폴더별 가상환경을 만든다
1) 폴더 생성
2) cmd에서 cd로 이동
3) ` python -m venv env ` 입력
4) vs code에서 터미널 Command Prompt로 열기
5) 해당 폴더로 이동 후 > ` .\env\Scripts\activate `입력 
6) 해당 폴더에만 모듈을 설치하려면 반드시 위의 명령어를 입력해서 (env)가 프롬프트 앞에 붙은 상태에서 모듈을 설치하면 됨

[모듈 설치]
1) ` pip install numpy ` 와 같이 실행해주면 모듈을 설치함
2) 프롬프트에 ` deactivate `를 입력하면 가상환경에서 빠져나옴


[파이썬 실행]
1) 가상환경(env)에서 ` python 파일명.py `를 입력하면 실행 됨
